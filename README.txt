HOW TO USE
1. Upload the entire folder to your web host, keeping the folder structure intact.
2. The site works as a static website and does not require a database.
3. The estimate form opens the visitor's default email app with a prepared estimate request.
4. If you later add a domain, update the Open Graph URL/image metadata and LocalBusiness schema if desired.
5. If the service area, business email, or phone changes, update those items in index.html.
